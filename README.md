## 🚀 Featured Projects

### 🏀 [StatCourt — NBA Analytics Platform](https://github.com/jaredmamaril/statcourt)
A full-stack NBA analytics application that lets users explore historical and current players, compare statistics, build custom lineups, and generate scouting reports. Built with Next.js, React, TypeScript, Python, and PostgreSQL.

### 🌐 [UIC-Inspired Landing Page](https://github.com/jaredmamaril/TOP-LandingPageProject)
A landing page inspired by the University of Illinois Chicago, built with HTML and CSS as part of The Odin Project. Features a navigation bar, welcome section, and a two-column layout.
